# Local crop-composition closeout candidate

This is a local review package, not a public data or software release. The existing
E1-E6 candidate and public v0.2.5 release are unchanged.

The two top-level directories are manuscript/ and lband-physics-pretraining/.
This version adds a descriptive crop-composition table to the supplement and concise
sample-selection text to the main paper. All eight excluded SMEX02 fields and all
51 excluded field-date records are labeled corn. The excluded records are 27.0%
of the 189-record complete target cohort. The table does not test vegetation
effects or crop-conditioned predictive error. No model experiment, frozen result,
figure, bibliography entry, or previously reported metric was changed.

The manuscript directory contains the verified TeX, PDFs, bibliography and placed
figures. The project directory contains the current code, processed inputs, frozen
results, E1-E6 post hoc outputs, site-label input, label-coverage report, and this
round's crop-accounting audit. The site file was supplied by the user and agrees
in format with NSIDC-0187; an official byte-level checksum was unavailable.
Each experiment's frozen protocol records its environment and input hashes.

This ZIP was checked by CRC and a per-file SHA-256 manifest. The manuscript PDFs
were compiled from the TeX versions in this ZIP. The ZIP does not claim that all
experiments were rerun. Before public deposit, review redistribution terms and
runtime instructions, publish a versioned release, verify its link, and only then
update the manuscript's availability statement.
